# Возможности StageCUE

## 1. Назначение и границы продукта

StageCUE — профессиональное Windows-приложение для ведения концертов, спектаклей, телетрансляций, конференций, фестивалей, инсталляций и прокатных шоу. Центральная сущность — **CueList**: упорядоченный сценарий, где каждая строка является действием, а оператор запускает выбранную строку командой **GO**.

- Целевая ОС: Windows 10/11; сайт также упоминает macOS только как среду разработки.
- Базовая конфигурация: не менее 8 ГБ RAM; для приложения заявлено около 300 МБ свободного места, плюс место для медиа.
- Обычная подготовка и воспроизведение не требуют постоянного интернета: медиа локальные.
- Дистрибутивы: Installer и Portable (Portable можно запускать без стандартной установки, в том числе с внешнего накопителя).
- Проекты, медиа, настройки и статистика, по заявлению сайта, не передаются разработчику.
- Все функциональные возможности одинаковы для лицензий; различается срок права использования: 7 дней, 30 дней, бессрочная и корпоративная.

## 2. Проект и переносимость

| Возможность | Поведение и нюансы |
| --- | --- |
| Новый проект | `Ctrl+N`; проекту назначают понятное имя. При создании нового шоу и при выходе с несохранёнными правками программа просит сохранить изменения. |
| Открыть | `Ctrl+O`, открывает ранее сохранённый проект. |
| Сохранить | `Ctrl+S`; файл имеет расширение `.stagecue`. Точка у имени проекта означает несохранённые изменения. |
| Сохранить как | `Ctrl+Shift+S`; создаёт отдельную копию в другом месте/под другим именем. |
| Папка медиа | Рядом с `.stagecue` создаётся `{Название проекта} MEDIA`; используемые медиафайлы копируются туда. Для переноса нужно копировать **и файл проекта, и эту папку**. Не закрывать приложение до окончания копирования крупных файлов. |
| Последние проекты | В «Файл → Последние файлы» — до 10 последних проектов. |

## 3. Модель CueList

### Типы строк

| Тип | Что делает |
| --- | --- |
| Audio | Воспроизводит аудиофайл через назначенное устройство и выходные каналы. |
| Video | Воспроизводит видео через выбранный дисплей, проектор или NDI-устройство. |
| Wait / Пауза | Ждёт заданное время как самостоятельный cue. В ранней шпаргалке перечислены быстрые интервалы 5 с, 10 с, 30 с, 1 м, 2 м, 5 м. |
| Note / Заметка | Не воспроизводит медиа; оставляет оператору текстовую пометку. |
| Group | Структурный контейнер; при запуске стартуют все вложенные треки одновременно. |
| GO | Адресно запускает выбранный трек или группу из любого места CueList. |
| STOP | Адресно останавливает выбранный трек или группу. |
| OSC | Отправляет произвольное OSC-сообщение внешней системе; содержит отдельное многострочное поле OSC-синтаксиса. |

> На обзорной странице среди этапов подготовки также названы Stop, LTC и MIDI. Детально задокументированы отдельные адресные GO/STOP, LTC-триггеры и MIDI-назначения; не следует автоматически считать LTC или MIDI отдельными строками CueList без проверки конкретной сборки.

### Добавление и сортировка

- Верхняя панель добавляет Audio, Video, Wait, Note, Group, GO и STOP; в версии 3.5 добавлена OSC-команда. Audio/Video открывают стандартный диалог файла.
- Один или несколько файлов можно перетащить из Проводника в CueList или сразу в группу. Формат определяет тип автоматически; в актуальных свойствах обычного трека ручного поля «Тип» нет.
- Поддерживаемое аудио: `mp3`, `wav`, `ogg`, `m4a`, `flac`, `aac`, `wma`.
- Поддерживаемое видео: `mp4`, `mov`, `webm`, `mkv`, `avi`, `m4v`.
- Порядок меняется drag-and-drop; номера cue пересчитываются автоматически. Трек можно перенести в группу, из группы или между группами.
- Множественный выбор: рамка мышью либо `Shift` + щелчок. Выделенный набор перемещается как единое целое.
- При GO запускается только **первый** из нескольких выделенных объектов, затем множественное выделение снимается, а курсор продолжает обычный маршрут.
- Начиная с 3.8.1 группа не может быть вложена в группу. Внутрь группы переносятся треки, а группы остаются на одном уровне.
- У группы есть шеврон `▶/▼` для сворачивания и раскрытия.

### Редактирование в строке

- Двойной щелчок по названию — переименование.
- Двойной щелчок по PreRoll — изменение задержки.
- Двойной щелчок по значку окончания — переключение `−|` / `→`.
- Актуальные руководство и страница «Возможности» прямо говорят: двойной щелчок **не запускает** cue, чтобы исключить случайный старт при редактировании. Старый PDF Quick Start описывает двойной щелчок как запуск; это историческое расхождение зафиксировано в [истории релизов](stagecue-release-history.md).

## 4. Свойства cue, трека и группы

| Свойство | Применение |
| --- | --- |
| Название | Отображаемое имя в CueList; редактируется в свойствах или прямо в строке. |
| Комментарий | Поле между названием и таймером для действия, технической подсказки или заметки. Двойной щелчок открывает редактирование. |
| Цвет | Спокойный полутоновый цвет для визуального деления сцен, блоков и типов контента. Не заменяет синий selected и ярко-зелёный playing. |
| PreRoll | Задержка до выполнения/старта cue. |
| Громкость | Уровень медиа; допускается менять во время воспроизведения. В ранней шпаргалке указан диапазон 0–100 %. |
| Аудиоустройство и каналы | Маршрутизация на звуковую карту и физические выходы/каналы. |
| Дисплей | Для Video: монитор, проектор либо доступное NDI-устройство. |
| Mix tracks / «Микшировать треки» | Если выключено (по умолчанию), новый трек или группа останавливает уже играющее. Если включено, стартует параллельно. Настраивается и у трека, и у группы. При нескольких слоях нужно контролировать суммарный уровень, чтобы не перегрузить мастер-выход. |
| Repeat / «Повтор» | `0` — один запуск, положительное число — количество автоповторов, «Без ограничений» — бесконечный повтор. Бесконечный повтор останавливается STOP, PAUSE или назначенной MIDI-командой. |
| После окончания | `−|` — остановиться и выделить следующую строку; `→` — автоматически запустить следующую строку. Работает только при естественном окончании трека/группы. |
| Триггеры | Отдельная вкладка свойств трека/группы; см. раздел 8. |

## 5. Ручное управление и воспроизведение

| Команда | Доступ | Поведение |
| --- | --- | --- |
| GO | Большая зелёная кнопка, `Space`, MIDI | Запускает строку под курсором: медиа, группу, паузу, заметку или служебный cue. После старта курсор переходит к следующей строке. |
| PAUSE | Жёлтая кнопка, `P`, MIDI | Приостанавливает на текущей позиции. Повторный PAUSE или GO продолжает с того же места. |
| STOP TRACK | Кнопка, `S`, MIDI | Останавливает только воспроизводимый трек под курсором. Если текущий трек не играет — ничего не меняется; в играющей группе останавливается только этот вложенный трек. |
| STOP ALL | Кнопка, `Esc`, MIDI | Аварийно останавливает все активные треки, группы, видео и таймеры. |
| Обычный FadeOut | STOP/MIDI-остановка | Звук затухает за фиксированные 1,5 с, а не обрывается мгновенно. |
| Таймер | Панель TIMER | Показывает Ready for GO / Playing / Pause, имя файла, прогресс, прошедшее и оставшееся время. В PDF — крупный обратный отсчёт `мин:сек.десятые` и полоса, по которой можно щёлкнуть или тянуть для перемотки аудио. |

## 6. Адресные команды GO и STOP

### GO

1. Добавить строку GO верхней кнопкой.
2. Перетащить на неё трек или группу; имя становится `GO — <название>`.
3. Запуск служебной строки стартует цель независимо от её физической позиции в CueList.

GO поддерживает PreRoll и флажок «Стоп воспроизводимых треков» / `Stop all previous`: перед запуском цели останавливаются уже работающие треки и группы. Имя адресного GO вручную не меняется. После выполнения курсор идёт к строке **после служебного GO**, а не к цели.

### STOP

1. Добавить STOP и перетащить на него цель; имя становится `STOP — <название>`.
2. Команда останавливает назначенный объект и поддерживает PreRoll.

| Параметр STOP | Диапазон / условие |
| --- | --- |
| FadeOut | 0–20 с; плавно снижает громкость цели. |
| CrossFade | 0–20 с; действует с режимом `→`, одновременно затухая текущий объект и поднимая следующий. Следующая строка должна быть воспроизводимым треком или группой. |
| Поведение | `−|` завершает выполнение STOP; `→` переходит к следующей строке CueList. |

## 7. Аудио и видео

### Аудио

- Обычные Windows-аудиоустройства и профессиональные интерфейсы.
- Многоканальный вывод: выбор физических выходов и каналов.
- ASIO (3.6.0): профессиональные интерфейсы, прямой выбор выходов и малая задержка.
- На сайте также заявлена работа с Dante Virtual Soundcard и Waves SoundGrid Driver как совместимыми системными аудиодрайверами Windows.
- Если названия устройств не видны, документация советует разрешить доступ к аудиоустройствам, переподключить карту и перезапустить StageCUE; ранний Quick Start уточняет возможный запрос доступа к микрофону только для корректного отображения имён, без записи микрофона.

### Video Out

- В свойствах видеотрека выбираются физический экран, проектор или NDI-устройство; главный экран Windows отмечается отдельно.
- Кнопка Video Out на верхней панели открывает/закрывает отдельное окно видеовыхода; горячая клавиша `Ctrl+Shift+V`.
- Видео выводится полноэкранно, без рамок и курсора, фон видеовыхода чёрный.
- После обычной остановки чёрный экран сохраняется: оператор может вручную переключить его на заставку или иной источник. Для выхода из полноэкранного режима сайт советует `F11`, затем закрыть видеоокно.
- Перед шоу: подключить дисплеи заранее, открыть Video Out, проверить выбор экрана, fullscreen, чёрный фон и отсутствие курсора.

### NDI

- При установленном совместимом NDI Runtime/драйвере NDI-устройство появляется среди дисплеев; выбор направляет видео в NDI-поток.
- StageCUE создаёт собственный NDI Sender; в 3.3.0 переход выполнен на NDI SDK 6.3.x, а установщик добавляет NDI Runtime 6 при отсутствии.
- Передача идёт по локальной IP/Ethernet-сети непосредственно из CueList, без отдельного захватчика/посредника, физического HDMI/SDI-тракта и карты захвата.
- Рекомендуемые проверки: перезапуск после установки Runtime, одна сеть у sender/receiver, разрешение StageCUE и NDI-компонентов в Windows Firewall, приём в NDI Monitor или совместимой системе (на сайте приведён пример Resolume).

## 8. Внешнее управление, синхронизация и автоматизация

### MIDI и клавиатура

- В настройках назначаются входящие MIDI-команды для GO, PAUSE, STOP TRACK и STOP ALL.
- Для назначения: подключить контроллер до запуска или обновить список устройств, выбрать функцию, включить ожидание MIDI-сообщения, нажать кнопку/педаль, сохранить и проверить несколько раз.
- MIDI Trigger на треке/группе использует MIDI Note или MIDI CC и соответствующее значение.

| Клавиша | Действие |
| --- | --- |
| `Space` | GO |
| `P` | PAUSE / продолжить |
| `S` | STOP TRACK |
| `Esc` | STOP ALL |
| `↑` / `↓` | Предыдущая / следующая строка |
| `←` / `→` | Свернуть / развернуть выбранную группу |
| `Ctrl+N` | Новый проект |
| `Ctrl+O` | Открыть |
| `Ctrl+S` | Сохранить |
| `Ctrl+Shift+S` | Сохранить как |
| `Ctrl+Shift+V` | Открыть / закрыть Video Out |

### OSC

- Поддерживается обмен OSC по Ethernet и отправка OSC cue из списка.
- Настройки: сетевой адаптер, порт (по умолчанию `53000`), Passcode или No Passcode.
- Для OSC Trigger программа автоматически формирует и показывает корректную команду для каждого cue; внешнее устройство/ПО отправляет её, чтобы дистанционно стартовать этот cue.

### LTC и часы

- В настройках LTC выбирается конкретный физический моно-вход звуковой карты.
- Внизу интерфейса отображается входящий LTC: бегущий таймкод при сигнале, прочерки при отсутствии.
- Внешний LTC Trigger задаётся как `часы:минуты:секунды:кадры`; cue запускается при достижении указанного значения.
- Внутренние часы компьютера запускают cue в заданное системное время.

### Защита от двойного GO

- Диапазон 0–60 с, значение по умолчанию 0.
- Блокирует только повторный GO; PAUSE, STOP TRACK и STOP ALL всегда доступны.
- Пока защита действует, GO получает красную рамку; по окончании интервала она исчезает.
- Рекомендация PDF: 0,3–1 с для частых cue; больше — для педали или ненадёжного контроллера.

## 9. Операционная готовность и диагностика

### Чек-лист

Перед репетицией: подключить аудио, MIDI, проектор и NDI-сеть; открыть проект; проверить пути к медиа, первый/средний/последний трек, PAUSE/STOP TRACK/STOP ALL; сохранить.

Перед шоу: отключить Windows-уведомления и энергосбережение; поставить курсор на первый cue; проверить интервал защиты GO и Video Out; проверить уровни, маршрутизацию и резервный план.

### Частые причины проблем

| Симптом | Проверить |
| --- | --- |
| Нет звука | Файл, громкость cue, аудиоустройство, каналы, Windows master, физические подключения. |
| Не видно проектор / видео | Расширение рабочего стола Windows, назначенный дисплей, Video Out и формат файла. |
| Нет NDI | Runtime/драйвер, перезапуск, firewall, сеть. |
| GO не повторяется | Красная рамка: действует защита от двойного нажатия. |
| `S` не останавливает | Курсор должен стоять на воспроизводимом треке; команда не остановит остальные. |
| Новый трек остановил старый | Включить Mix tracks у нового трека/группы. |
