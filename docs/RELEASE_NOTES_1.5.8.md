# Qlisa 1.5.8

## Project files

- `.qlisa` is the primary project file extension. On Windows, the installer
  registers `.qlisa` for Qlisa and supports opening these files from File
  Explorer or through **Open with**.
- Existing `.inkue` projects remain supported. Saving an opened `.inkue` project
  keeps its current path and extension. **Save As** defaults to `.qlisa`.

## Cue toolbar

- The Cue toolbar adapts to the available window width and keeps its actions on
  one row. Actions that do not fit move into **More**.
- Controls on the right side remain fixed while the toolbar adapts.
