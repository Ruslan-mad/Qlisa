# Qlisa 1.5.16

## Изменения

- Для видео добавлен параметр «Чёрные поля» в настройках слоя. Для новых и старых видео он включён по умолчанию. Для изображений параметр доступен и выключен по умолчанию. Изменение применяется сразу, в том числе к воспроизводимому cue.
- Индикатор следующего cue показывает направление перехода. Зелёный маркер показывает, что cue уже воспроизводится; оба индикатора остаются в колонке указателя списка.
- Кнопка PAUSE/RESUME действует на выбранные активные cue в текущем списке. Пустой выбор отключает кнопку. Выбор группы и её номера не вызывает повторные команды.
- Кнопка остановки всех cue получила более спокойное оформление. При наведении она подсвечивается красным.

## English summary

Qlisa 1.5.16 adds a per-cue black-bars option for video and image layers, with video enabled and images disabled by default. The cue list distinguishes the next cue from cues that are already running. Pause and resume target selected active cues in the current list, and the stop-all button uses a quieter style with a red hover state.
