# Qlisa 1.5.21

- Added Timer cues with configurable duration and end signals.
- Added editable volume envelopes in Preview and envelope display in Live.
- Improved visual cue geometry controls, output cropping, and aspect-ratio handling.
- Added PDF and PowerPoint import as static slides, presentation review and navigation, embedded and locally linked video cues, and Page Up/Page Down navigation.
- Added quick controls to cue cards and improved footer placement.
- Improved media conversion for stream-copy eligibility, output validation, long filenames, and stale cue assignments.
- Fixed video audio lifecycle handling during transport changes.
- Added a self-hosted Windows runtime kit with explicit component update and repair controls. Compatible kits persist across app updates.
