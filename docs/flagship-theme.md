# Режим Stage

Режим Stage — новая тема рабочего пространства для работы во время шоу. В
локальном кандидате 1.5.12 он доступен в Preferences → Appearance. Новые
профили используют Stage по умолчанию. Сохранённые профили старых тем сохраняют
свою тему. Кандидат ожидает одобрения пользователя и не опубликован.

## Интерфейс

- Верхняя панель высотой 64 px показывает бренд и проект, состояние Modified или
  время последнего подтверждённого сохранения. Если время сохранения неизвестно,
  отображается нейтральный статус Saved.
- В центре находится Cue List. Слева размещена панель Active Cues, справа —
  Inspector. Боковые панели можно скрывать и открывать независимо; их состояние
  сохраняется. Старое сохранённое поле `rightPanel` переносится при миграции
  раскладки.
- Кнопки Cue расположены слева в панели высотой 62 px; Active Cues и Inspector —
  справа. Используются значки Phosphor.
- Панель управления показывает дату и часы с обновлением раз в секунду,
  существующее управление физическим полноэкранным режимом и системные кнопки
  окна.
- Большие GO, STOP и PAUSE сохраняют существующие действия транспорта. Пробел
  запускает Cue, Escape выполняет STOP. Кнопка PAUSE управляет всеми активными
  Cue. Клавиша P управляет только выбранным Cue; подпись под кнопкой указывает
  эту область действия.
- Индикаторы показывают настроенные выходы из Preferences. Уровни VU и Master
  используют существующую логику аудиомикшера.
- Компактный Cue List сохраняет настройку колонок Stage отдельно под ключом
  `qlisa_stage_column_config_v1`. Все доступные колонки можно включить вручную;
  старые настройки колонок остаются доступны старым темам. Группы используют
  авторские цвета: группы и Number cues используют заливку 45%, а обычные
  строки — 28%. Белый тег получает заливку 20% для групп/Number cues и 12% для
  обычных строк, чтобы сохранить контраст текста. Running и paused в Active Cues
  используют зелёный `#34d399` и оранжевый `#fb923c`. Выбранные строки сохраняют
  отдельное выделение.

Режим меняет представление и локальные настройки интерфейса. Он не вводит новую
систему маршрутизации и не меняет движок воспроизведения.

- [ ] Переключить старый профиль на Stage и обратно. Проверить сохранность
  выбранной темы, а также открыть профиль, сохранённый до появления поля темы.
- [x] **Браузерная UI QA с локальной IPC-заглушкой:** Active Cues и Inspector
  скрывались и открывались независимо; rails восстанавливались, состояние
  раскладки пережило перезагрузку окна. Дополнительно в production app обе
  панели скрывались отдельно и rails восстанавливались. Это не проверяет
  реальный backend transport.
- [x] **Браузерная UI QA с локальной IPC-заглушкой:** визуально проверены
  заголовок, Cue List, Inspector и footer. Макет шириной 1280 px проверен до и
  после уплотнения footer; финальная высота footer — 96 px. Это визуальная
  проверка UI, не проверка работы нативного окна.
- [x] В production app начальный статус без известного времени был нейтральным

- [ ] Проверить дату, часы с обновлением раз в секунду, системные кнопки окна и

- [ ] На реальном backend проверить GO, STOP, PAUSE, Space, Escape и P. Подтвердить,

  Переключиться на старую тему и подтвердить, что её настройки колонок не
  изменились. Проверить доступность всех колонок.
- [ ] Проверить авторские цвета групп и читаемость выделенных строк.

Браузерная UI QA завершена успешно с реальными компонентами приложения и
локальной IPC-заглушкой. В финальном просмотре нет видимых дефектов уровней
P0–P2. Осталась заметка уровня P3: исходная плотность строк Cue List составляет
26 px; сохранять её для совместимости с существующей виртуализацией. Функциональные
медиа не проверялись: доступен только иллюстративный источник.

Автоматические проверки: 486 frontend-проверок, TypeScript, `pnpm build` и 42
Rust-теста настроек прошли. `pnpm tauri:check` также завершился успешно. Эти
проверки подтверждают сборку, но не физическое воспроизведение. Кнопка закрытия
главного окна (×) проверена; процесс PID 12668 завершился. Maximize, minimize,
fullscreen, transport playback и оборудование не проверялись. Сборка установщика
и выпуск не подтверждены.
