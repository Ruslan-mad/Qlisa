# История функций и релизные уточнения StageCUE

| Версия / публикация | Изменения, влияющие на продукт |
| --- | --- |
| 3.2.1 | FadeOut 1,5 с при обычной остановке; Mix tracks; Stop Track (`S`, MIDI); рамочное/Shift множественное выделение; блокировка повторного GO 0–60 с и красная рамка; NDI среди видеовыходов; after-end `Stop` / `Auto GO`; адресный GO с PreRoll/stop previous; адресный STOP с PreRoll, FadeOut и CrossFade до 20 с. |
| 3.3.0 | Исправлена исходная визуальная индикация PAUSE и читаемость поля защиты GO; переработан NDI Sender, NDI SDK 6.3.x, установка NDI Runtime 6 при отсутствии; prompt сохранения при New и выходе. |
| 3.5.0 | Repeat (0, число, бесконечно); полноценный OSC (adapter, port 53000, passcode); OSC cue и многострочный синтаксис; выбор LTC mono-input и нижняя LTC-индикация; вкладка Triggers: внешний LTC, часы ПК, MIDI Note/CC, OSC trigger. |
| 3.6.0 | ASIO: профессиональные многоканальные интерфейсы, физические выходы, низкая задержка, при сохранении обычных Windows-аудиоустройств. |
| 3.8.0 | Полутоновые user colors у треков/групп; comments между названием и таймером; до 10 Recent Files. |
| 3.8.1 | Группа больше не вкладывается в группу; drop line и group outline при drag-and-drop; авто-прокрутка к playing cue и, по возможности, ещё трём следующим. |
| 3.8.3 | Большой зелёный play-triangle слева от номера cue; comments обычным начертанием вместо тонкого курсива; системная light theme наряду с dark. |

## Важные версии-даты не подтверждены

Страницы релизов перечисляют номера, но в изученных материалах не дают единой надёжной таблицы дат сборок. В документации лучше использовать номер версии, а фактическую дату сборки читать в Settings → «О программе».

## Исторические расхождения документации

| Тема | Ранний источник | Актуальный источник / правило для спецификации |
| --- | --- | --- |
| Двойной щелчок по cue | PDF Quick Start: запускает команду. | Страница руководства и полный User Manual: редактирует строку, не запускает. Использовать текущую безопасную логику редактирования. |
| Ручной выбор типа media | Quick Start перечисляет свойство Type. | Актуальное руководство: тип определяется по формату при добавлении и не выбирается вручную у обычного трека. |
| Остановка Video Out | Обзорная страница упрощённо называет Stop/Esc. | Руководство уточняет: чёрный экран сохраняется; для выхода из fullscreen — `F11`, затем закрыть окно. |

## Не функциональные публикации

- `2111-2` описывает переход на 7/30-дневные и бессрочные лицензии, промокоды и получение license file; новых функций не заявляет.
- `stage-cue-ndi` объясняет схему StageCUE → Ethernet → NDI → Resolume и не добавляет отличающейся от релизов функции.
- `qlab-analog-windows` и `stagecue-analog-qlab-windows` — позиционирование StageCUE как Windows-альтернативы QLab, с двумя адресами проекта; функциональные утверждения уже внесены в карту возможностей.
