# Qlisa 1.5.14

## Изменения

- Добавлена настраиваемая строка состояния внизу главного окна. По умолчанию
  включены восемь метрик: статистика выбранного Cue List, CPU, GPU, VRAM и
  RAM. Можно менять сторону и порядок 13 метрик. Audio gaps, Video FPS,
  network drops, память процесса и место на диске выключены по умолчанию.
  Пользователь может выбрать GPU для показателей загрузки и выделенной памяти.
- Исправлено сохранение настроек строки состояния в системных параметрах.
- Главное окно запоминает обычное положение, размер клиентской области и
  состояние максимизации. Если сохранённая позиция больше не пересекается с
  доступным монитором, окно возвращается в рабочую область основного монитора.

## Проверки

- 15 целевых Rust-тестов проверили сохранение настроек; три Rust-теста
  проверили восстановление и ограничение положения окна.
- `pnpm tauri:check` прошёл и собрал debug-приложение.
- На Windows проверены сохранение настроек строки состояния и восстановление
  положения, размера и состояния максимизации главного окна.
- Реальные FPS дисплея, аудиопотери на рабочем оборудовании и поведение
  NDI/SRT-приёмников этими проверками не подтверждены. Проверка обновления
  между версиями не проводилась.

## English summary

Qlisa 1.5.14 adds a configurable 13-metric status bar, fixes persistence of its
settings, and restores the main window's normal position, client size, and
maximized state across launches.
